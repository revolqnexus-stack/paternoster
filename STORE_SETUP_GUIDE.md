# LRB Store Setup Guide

## Why Your Theme Looks Bland

Your theme has all the LRB styling in place, but you need to:
1. **Add products to your Shopify store**
2. **Create collections** (Fiction, Non-Fiction, Poetry, etc.)
3. **Configure sections in theme customizer**
4. **Upload product images**

## Quick Setup Checklist

### 1. Add Sample Products (5-10 minutes)
Go to: https://admin.shopify.com/store/pater-noster-jwjbtasv/products

Add at least 3-5 products with:
- **Title**: Book title (e.g., "The New York Trilogy" by Paul Auster)
- **Price**: £15.99
- **Description**: Book description
- **Images**: Book cover images
- **Type**: "Books" or "Merchandise"

### 2. Create Collections (3 minutes)
Go to: https://admin.shopify.com/store/pater-noster-jwjbtasv/collections

Create collections:
- Fiction
- Non-Fiction  
- Poetry
- LRB Merchandise
- New Arrivals
- Staff Picks

### 3. Configure Theme Sections (5 minutes)
Go to: https://admin.shopify.com/store/pater-noster-jwjbtasv/themes

1. Click **Customize** on the LRB Store theme
2. On the homepage, configure:
   - **Hero Featured Product**: Select a featured product
   - **Shop By Type**: Link each block to a collection
   - **Promotional Banners**: Add text and links
   - **About Store**: Edit the text

### 4. Visual Comparison Checklist

Compare your store against: https://www.lrbstore.co.uk/

✅ **Typography**: Crimson Text headings + Inter body text  
✅ **Colors**: Black text on white, subtle greys  
✅ **Spacing**: Generous white space  
✅ **Layout**: Clean grid-based design  
✅ **Buttons**: Simple bordered buttons  
✅ **Product cards**: Minimal with clean borders
